# LinkHUB　零式　MINI MAX簡易エディタ

MiniMax-H3（映像と音声を同時に生成するAIモデル）を、**フォームを埋めるだけ**で使えるようにするWindowsアプリです。

ComfyUIのノードを繋ぐ必要はありません。画像を選び、動きを日本語で書き、ボタンを押すだけで、音声つきの動画が生成されます。

> **AIに導入を任せる場合**
> Claude Code や Codex などのAIエージェントに、このリポジトリの [AI_SETUP.md](AI_SETUP.md) を読ませてください。
> 環境チェックからモデル配置の確認まで、AIが順番に進められるように書いてあります。

> **連続生成の追加パック: 連創型 幻想（RENSO）**
> 共有フレームで繋がった動画を一気に複数本作る画面を、別リポジトリで配布しています。
> このエディタに追加して使います: [ShironaLink/LinkHUB-MiniMax-Renso](https://github.com/ShironaLink/LinkHUB-MiniMax-Renso)

---

## 何ができるか

| モード | 内容 |
|---|---|
| 文章から | プロンプトだけで映像と音声を作る |
| 画像を動かす | 1枚の絵を動かす。終了フレームも指定できる |
| 参照して作る | 画像・動画・音声を参照に、姿や声色を寄せて作る |
| マネキン | マネキン動画の動きをキャラ設定画へ移す |

生成後は映像と音声を自動検査し、黒画面・無音・参照無視などの失敗を検出します。

## 必要なもの

### 1. パソコン

- Windows 11
- **NVIDIA製GPU（VRAM 8GB以上）**
- Python 3.12（`py` ランチャーから使えること）
- 空き容量 **70GB以上**（モデルが大きいため）

VRAM 8GBでも動作しますが、生成できる長さと解像度に上限があります（後述）。

### 2. ComfyUI

このアプリはComfyUIをエンジンとして使います。**先にComfyUIを導入してください。**

[Stability Matrix](https://lykos.ai/) から入れるのが簡単です。導入後、`Packages\ComfyUI` フォルダの場所を覚えておいてください。初回起動時にそのフォルダを聞かれます。

**ComfyUI本体は書き換えません。** `custom_nodes` にこのアプリへのリンクを1つ作るだけです。

動作確認済みは **ComfyUI 0.37.0** です。あわせて以下が必要です。

- **[ComfyUI-GGUF](https://github.com/city96/ComfyUI-GGUF)**（必須）— テキストエンコーダーがGGUF形式のため
- **RTX 20シリーズの場合のみ**: 同梱の `extras\genso_sm75_fallback` フォルダを ComfyUI の `custom_nodes` へコピーしてください。ComfyUI 0.37.0 の高速化カーネルがRTX 30シリーズ以降専用で、20シリーズでは生成が必ず途中で落ちるためです（入れておくと純PyTorchの処理に切り替わります。30シリーズ以降では何もしません）

**モデルはこのアプリに同梱できません**（1ファイル20GB近くあるため）。以下をダウンロードして、ComfyUIの対応フォルダへ配置してください。

## 導入手順

### EXE版（おすすめ・Python不要）

1. ZIPを展開します
2. **`GENSO.exe` をダブルクリック**
3. 初回だけ「ComfyUI の場所を教えてください」という画面が出ます。`Packages\ComfyUI`（`main.py` があるフォルダ）を選んでください

フォルダを確認したうえで設定を保存し、ComfyUIへのリンクを自動で作り、エンジンを起動します。2回目以降はこの画面は出ません。ComfyUIの設定を触る必要はありません。

> **⚠ ウイルス対策ソフトに削除される場合があります**
>
> `GENSO.exe` が起動しない、または勝手に消える場合、Windows Defender などが誤検知しています。**これはPythonアプリをEXE化するツール（PyInstaller）で作られた実行ファイル全般に起こる既知の誤検知**で、実際にウイルスが入っているわけではありません。
>
> 対処するには、展開したフォルダを除外設定に追加してください。
>
> Windowsセキュリティ → ウイルスと脅威の防止 → 設定の管理 → 除外の追加または削除 → フォルダを選択
>
> 気になる場合は、次項のソース版をお使いください。中身はすべて公開されています。

### ソース版（Python 3.12が必要）

1. **`setup.bat` を実行** — 専用のPython環境を作ります（1〜2分）
2. **`run.bat` を実行** — 以降はEXE版と同じです

## 使い方の勘所

### VRAM 8GB での上限（8GB機を使う場合のみ）

**以下の数値は VRAM 8GB のGPU（RTX 2080 SUPER）での実測値です。** 12GB以上のGPUをお使いの場合はこの制限は当てはまりません。

アプリは起動時にGPUのVRAM容量を検出し、**8GB前後の場合だけこの警告を出します**。それより大きいGPUでは、上限が未検証であることを添えて現在値だけを表示します。

このモデルは約21GBあり、8GBのVRAMには収まりません。足りない分はシステムメモリへ置かれ、GPUがそこを読みながら動きます。**この「はみ出し量」が一定を超えると、生成時間が突然数倍になります。**

上限は2つあり、**どちらか一方でも超えるとアウト**です。

#### 1. フレーム数 — 107まで（4.46秒）

864×480での実測値です。

| フレーム数 | 尺 | 所要時間 |
|---|---|---|
| 73 | 3.04秒 | 7分 |
| 90 | 3.75秒 | 9分 |
| **107** | **4.46秒** | **10分** ← 安定する上限 |
| 124 | 5.17秒 | **14分／19分／34分／48分／65分**（同じ設定でばらつく） |

107までは尺に比例して素直に伸びますが、124では同じ設定でも4.6倍の幅で暴れます。**長い動画は分けて作り、あとで繋ぐのが確実です。**

#### 2. 解像度 — 1フレーム1,620トークンまで

トークン数は `(横÷16) × (縦÷16)` で計算します。

| 解像度 | トークン | 判定 |
|---|---|---|
| 480×608 | 1,140 | ○ 速いが細部がにじむ |
| 576×704 | 1,584 | ○ 縦構図の推奨値 |
| 864×480 | 1,620 | ○ 横構図の推奨値 |
| 640×800 | 2,000 | **× 1ステップも進まない** |

**解像度の上限はフレーム数と交換できません。** 640×800はフレーム数を107→90に減らしても駄目でした。活性値バッファの大きさが1フレームの解像度だけで決まるためです。

#### VRAMが多い場合

12GBならフレーム数・解像度とも上限が上がります。24GBあれば**モデル全体がVRAMに収まる**ため、システムメモリを経由しなくなり、速度そのものが大きく変わります。

### キーフレームの使い方

開始フレームと終了フレームの両方を指定すると、その間をAIが埋めます。**両方の画像は同じ構図・同じカメラ位置で作ってください。** 画角がずれていると、AIが「カメラが動いている」と解釈して画面全体が揺れます。

### 動きの書き方

「何かが動く」とだけ書くと、AIは想像で誇張します。実例として、

- 「湯気が立つ」→ 画面を覆うほど噴き上がった
- 「水が流れる」→ 受け皿を外して床にこぼした

**どこから、どこへ、どの程度動くのか**まで書いてください。書かなければ、その要素は静止したままになります。

### 音声について

音の記述を書かないと、AIが映像から音を推測します。人の声を入れたくない場合は、**声や息に関する言葉を一切書かない**でください。「声を出さない」と否定形で書くと、かえって声が出ることがあります。

環境音だけが欲しいときは、欲しい音（風、水、鳥など）だけを並べてください。

### 日本語プロンプトの翻訳（任意）

ローカルの [Ollama](https://ollama.com/) を導入していれば、日本語で書いたプロンプトを英語へ変換できます。台詞・字幕・参照タグは翻訳に出さず、そのまま保持します。

Ollamaがなくても、英語で直接書けば全機能が使えます。

## 生成が遅いと感じたら

このアプリはVRAMを限界まで使います。**同時に他のGPU作業をしないでください。**

- 生成中に動画を再生しない
- 生成とアップスケールを同時に走らせない
- 生成が終わったら、次の作業の前にアプリを閉じてVRAMを解放する

これを守るだけで、生成時間が数倍変わります。

### 1ステップ目が20分近く進まない場合

エラーは出ず、GPU使用率が100%のまま極端に遅い場合は、VRAMからあふれた分をWindowsが黙って共有メモリへ逃がしている可能性が高いです。

NVIDIA コントロールパネル →「3D 設定の管理」→「**CUDA - システムメモリ フォールバック ポリシー**」を「**システムメモリ フォールバックを優先しない**」にして、アプリの「エンジン再起動」を押してください。

## 開発

`tests\` にテストが入っています。ComfyUIのPython環境から実行できます。

```
"<ComfyUIのパス>\venv\Scripts\python.exe" -m pytest tests
```

このアプリはComfyUIの `custom_nodes` として動くため、テストもComfyUI側の環境で走らせる必要があります。
